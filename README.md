# ຈົດລາຍຮັບ-ລາຍຈ່າຍ (Money Tracker)

PWA ພາສາລາວ ສຳລັບຈົດລາຍຮັບ-ລາຍຈ່າຍ (ກີບ, ບາດ, ໂດລາ, ຢວນ) ພ້ອມ AI ອ່ານສະລິບ.

- **Front-end:** GitHub Pages (`index.html`, `manifest.webmanifest`, `sw.js`, `config.js`)
- **Back-end:** Google Apps Script (`Code.gs`) ຕໍ່ກັບ Google Sheets ແລະ Gemini API
- `config.js` ເກັບລິ້ງ Web app `/exec`; ລະຫັດເຂົ້າໃຊ້ (APP_TOKEN) ເກັບໃນ Script Properties ເທົ່ານັ້ນ — ບໍ່ຢູ່ໃນ repo ນີ້.

ຕິດຕັ້ງ: Android (Chrome › ⋮ › Add to Home screen) · iPhone (Safari › Share › Add to Home Screen)
